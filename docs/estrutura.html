Estrutura de Arquivos e Padrões de Código

1 Árvore anotada

little-paw-coffee/
├── *.html                  Uma página por arquivo (nomes em português)
├── assets/css/main.css     Tokens de design (cores, espaçamentos) e layout
├── assets/css/accessibility.css  Foco visível, movimento reduzido, alto contraste
├── assets/css/admin.css    Estilos do painel da galeria
├── assets/js/security.js   Base de segurança — carregado primeiro
├── assets/js/i18n.js       Traduções (data-i18n)
├── assets/js/lgpd.js       Consentimento
├── assets/js/data.js       Dados estáticos (catálogo, eventos, galeria)
├── assets/js/cart.js       Carrinho
├── assets/js/layout.js     Cabeçalho/rodapé e navegação
├── assets/js/main.js       Inicialização global

├── database/               schema.sql e seed.sql
└── docs/                   Documentação (este conteúdo)

2 Guia de estilo

  • Arquivos e URLs: português, minúsculas, sem acentos (cardapio.html, eventos.html).
  • Banco de dados: snake_case em português (itens_pedido, preco_centavos).
  • JavaScript: camelCase para funções e variáveis, PascalCase para objetos/classes (Cart, ConsentManager), MAIÚSCULAS para constantes (CATALOG).
  • Padrão de módulo: cada arquivo é uma IIFE em modo estrito que expõe um único objeto no escopo global; a comunicação entre módulos usa eventos personalizados (lpc:ready, lpc:langchange, lpc:cartchange, lpc:consentchange).
  • Segurança: nunca usar innerHTML com dados variáveis; usar el() e textContent; acessar o armazenamento só via SafeStorage; sem scripts embutidos (CSP).
  • Textos: português do Brasil conforme a norma culta; todo texto visível deve ter chave de tradução.
  • Valores monetários: sempre em centavos (inteiros).
(function (global) {
  'use strict';
  const MeuModulo = {
    iniciar() { /* ... */ }
  };
  document.addEventListener('lpc:ready', () => MeuModulo.iniciar());
  global.MeuModulo = MeuModulo;
})(window);

3 Como adicionar uma nova página

  1. Copie index.html para o novo arquivo (ex.: blog.html), mantendo as metatags de segurança, os contêineres #site-header/#site-footer e a ordem dos scripts.
  2. Substitua o conteúdo de <main>, usando atributos data-i18n em todos os textos.
  3. Registre o item de navegação no mapa de rotas de assets/js/layout.js.
  4. Adicione as chaves de tradução (PT-BR e EN) em assets/js/i18n.js, incluindo o título do menu.
  5. Se houver lógica própria, crie assets/js/pages/blog.js e inclua-o por último.
  6. Teste a navegação por teclado, o contraste e a troca de idioma.

4 Como adicionar um item ao cardápio

  1. Inclua um objeto em CATALOG (assets/js/data.js) com identificador único, categoria (hot, cold, snacks ou desserts), preço em centavos e nomes/descrições em PT-BR e EN.
  2. Opcionalmente, adicione a imagem em assets/images/.
  3. Para o banco, insira a linha correspondente em itens_cardapio no seed.sql.
INSERT INTO itens_cardapio (id_item, nome_pt, nome_en, descricao_pt, descricao_en, categoria, preco_centavos, emoji, vegano)
VALUES ('cookie-patinha', 'Cookie Patinha', 'Paw Cookie', 'Cookie em formato de patinha.', 'Paw-shaped cookie.', 'desserts', 900, '🍪', 0);

5 Como adicionar um evento

  1. Inclua um objeto em EVENTS (data.js) com identificador, data (AAAA-MM-DD), horários, vagas, preço em centavos e textos bilíngues.
  2. Insira o registro correspondente na tabela eventos do seed.sql.

6 Internacionalização (i18n)

  1. Adicione a chave nos dois dicionários de i18n.js ('pt-BR' e en).
  2. No HTML, use data-i18n="chave" para texto e data-i18n-attr="atributo:chave" para atributos (ex.: aria-label, placeholder).
  3. Para textos gerados em JavaScript, use a função de tradução do objeto I18n e ouça lpc:langchange para renderizar novamente.
<h2 data-i18n="blog.title">Blog da Cafeteria</h2>
<input data-i18n-attr="placeholder:blog.search">
