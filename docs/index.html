Documentação do Projeto Little Paw Coffee

Resumo do projeto

O Little Paw Coffee é o site de uma cafeteria temática voltada à comunidade furry e ao público em geral. O site é estático (HTML5, CSS3 e JavaScript puro), bilíngue (português do Brasil por padrão, com botão para inglês), acessível (WCAG 2.1 AA) e projetado conforme a Lei Geral de Proteção de Dados Pessoais (LGPD, Lei n.º 13.709/2018).

  • Páginas: Início, Cardápio Temático, Galeria de Arte Furry (com envio de imagens pelo administrador), Eventos, Carrinho e Privacidade.
  • Carrinho fictício: gera um código de retirada no balcão; não há meios de pagamento nem coleta de dados de cartão.
  • Banco de dados: esquema SQL com 9 tabelas (database/schema.sql) para a futura versão com servidor.
